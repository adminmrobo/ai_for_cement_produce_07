28일을 기다리지 않고, 오늘 만든 시멘트의 강도를 믿을 만한 숫자로 말할 수 있을까?

회귀·분류 모델로 28일 강도와 불량을 예측하는 4단계 실습이다. 생성 AI에 프롬프트를 주고, 받은 코드를 Colab에서 돌리고, 결과를 공정 엔지니어의 눈으로 읽는다. 맞힐 수 있나 → 믿어도 되나 → 왜 그렇게 맞혔나 → 그래서 어떻게 만들까.

실습 방법

  1. Google Colab에 접속한다.
  2. 해설 페이지 각 단계의 "실습 프롬프트"를 생성 AI에 붙여 넣는다.
  3. 받은 코드를 Colab 셀에 붙여 넣고 실행한다. 오류가 나면 오류 메시지 전체를 다시 AI에게 준다.
  4. 결과 숫자를 보고 "공정적으로 말이 되나?"를 묻는다.

생성 AI는 같은 프롬프트에도 다른 코드를 낼 수 있다. 페이지의 숫자와 똑같이 맞추려면 페이지에 접어 둔 "실제로 사용한 코드"를 쓰거나, 위의 CSV를 업로드해 쓴다.
